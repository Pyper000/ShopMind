# ShopMind 上线与评测任务单

更新时间：2026-10-21

> 历史计划快照：本文记录 2026-10-21 的公网验收状态，不代表当前实现或服务状态。当前本地验收与证据边界以 [2026-10-23 数据证据评测](aipm-data-evidence-review-20261023.md) 和 [本地租房/场景演示验收](local-rental-demo-acceptance-20261023.md) 为准。本文不应被当作已上线或已完成的证明。

## 验收目标

用户看到的 ShopMind 页面使用 `MainAgent -> task_dispatch(SearchAgent)` 购物方案链路；`TradeAgent` 保持未激活。MainAgent 负责从自然语言更新版本化方案，SearchAgent 按本轮变更做候选过滤重排、局部召回或全量重召回。前端需显示多轮方案变化和搜索过程。公网场景评测必须请求这套 Python AgentScope API，不能把旧的 JS 演示 API 结果混算。

## 产品叙事

- 问题来源：用户为了旅行、租房、送礼等任务，常从小红书清单或零散建议开始，再自行核对家中已有物品、缺项与预算。ShopMind 把“我要完成什么任务”作为入口，而不是要求用户先知道商品关键词。
- 目标用户假设：第一次执行某类生活任务、采购经验有限，担心买多、买错、买漏，且愿意为省心和方案完整性付费的人。高净值人群是待验证的细分与付费假设，不是已证明的用户结论。
- 产品承诺：先形成可调整的最小够用清单，显式区分已有、必买、按需、待确认；只为明确待购项找候选，说明推荐理由、取舍与未知。
- 与通用商品助手的差异假设：以任务完成和采购决策为目标，不以多展示商品为目标。没有同场景对照测评前，不声称淘宝或其他助手“只能推荐三两件”或 ShopMind 效果更好。
- 当前北极星方向：任务方案完成率 / 用户决策信心；由于目前是虚拟商品目录和脚本测试，点击、转化、GMV、复购及 ROI 暂不具备可信测量条件。
- 成本验证门槛：记录每个任务的模型调用数、Token、供应商账单成本和延迟；与目标用户对“省时、省心、少买错”的付费意愿一起判断高成本服务是否成立。

## 当前证据

- Python 项目依赖 AgentScope 2.x；当前本机运行时是 AgentScope 2.0.6、Python 3.12.1。
- 本轮全量 Python 测试 `306 passed`；前端 `npm run build` 通过；独立 JS 目录 `node --test api/chat.test.mjs` 为 `21 passed`。
- `api/catalog.json` 有 16 个一级类目、480 个模拟商品；这是 JS 演示目录，不代表 Python 检索目录规模。
- 2026-10-19 历史公开 API 冒烟记录只有 1 个场景：1 次请求成功、16.6 秒、2/2 个待购槽位有候选、3 张候选卡、必需候选最低价 118 CNY / 预算 300 CNY。它不是 10 场景评测，也没有证明当时使用了当前 AgentScope 版本。
- 当前 Vercel 首页可打开，但 `/commerce/intents` 返回 404；`/api/chat` 是独立 JS API，不是 Python AgentScope 后端。`render.yaml` 声明的 Render 服务地址尚未确认部署，探测到的猜测地址不能作为发布证据。
- Landing 的 LiveChat 已改为 POST SSE，能接收 Python 后端的方案、Agent、工具和 token 事件；端点事件顺序有自动化测试。真实模型公网流仍未验证。
- Render 配置已允许当前 Vercel / GitHub Pages 来源跨域访问；Vercel 项目仍须设置 `VITE_API_BASE` 指向已确认的 Python AgentScope 服务。
- 当前工作区有多处用户未提交改动；不得重置、覆盖或擅自提交。

### P2：运行 10 个合成场景

- [ ] 用 `eval/shopmind_scenarios.yaml` 的 10 个场景，通过 `scripts/eval_scenarios.py --base-url <已确认的 AgentScope API>` 运行三轮脚本化对话。

## 六问自查

1. 场景判断：痛点来自产品假设与公开清单类场景观察；尚无真人访谈验证，避免写成已验证用户需求。
2. 技术选型：当前 AgentScope 2.x + Python API；部署环境、每任务模型成本和链路延迟需在目标公网服务测得。
3. 评测体系：已有单元 / 集成测试和旧版单场景冒烟；新增 10 场景脚本尚未对当前 AgentScope 公网服务运行。
4. 兜底策略：本地测试覆盖规则与检索分支；需通过公网断网、模型失败、空候选等故障场景验收。
5. 数据闭环：当前评测记录落在本地文件 / 浏览器，不是线上用户行为数据闭环；Bad Case 由项目负责人手工回收。
6. ROI：商品和交易均为模拟数据，不足以计算 GMV、转化率、收入或真实 ROI。
