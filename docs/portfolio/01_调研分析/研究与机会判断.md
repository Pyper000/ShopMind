# 研究与机会判断

一句话：现有材料支持“用户准备方式存在差异”，尚未证明 ShopMind 的需求规模；先验证陌生、多品类任务中的整理与核对负担。

更新：2026-10-25。本文件提炼[10月24日原始研究整理](../../shopmind-background-research-20261024.md)，不新增访谈或问卷结果。

## 1. 背景证据：定量与定性分开

| 材料 | 已知事实 | 能得出的结论 | 不能推出 |
| --- | --- | --- | --- |
| 创始人欧洲旅行经历 | 找经验清单、复制备忘录、确认缺项后到电商搜索 | 可提出跨来源整理与决策衔接假设 | 不能代表目标用户总体 |
| 群友摘要 n=5 | 1人明确倾向用清单；其余缺逐人原始答案 | 值得追问差异；短途可能低需求 | 不能写20%需求率或80%反对 |
| A–D 摘要 | 记忆/当地补买、看天气/衣柜、首次养猫做功课、临行前线下试衣等 | 本次可用性、时间、信任和偏好影响准备 | 与n=5是否重叠未知，不能合并人数 |
| CAT-01 | 有经验养猫者先基础后升级，关注来源和信任 | 分阶段与可信性可能比清单长短重要 | 不能代表新手养猫，也不能证明遗漏痛点 |
| TRIP-02 | 出行靠记忆、搬家倾向先带刚需再补 | 反例有助收窄场景，事后补齐可能合理 | 截图非完整逐字稿；搬家经历需核实 |
| 工程量化结果 | 395个自动化测试通过；有SSE/截图 | 当前断言范围内的工程行为可复现 | 不能证明用户满意、需求规模或商业效果 |

目前没有可用的去重真实用户任务量、准备时长基线、漏项频率或损失金额。宏观零售与旅游规模只作母市场背景；旧研究中的宏观数字保留原始出处，本轮未用其推算 TAM/SAM/SOM。

## 2. 痛点—价值—验证

| 假设 | 对应需求 | 价值大小如何衡量 | 反证 |
| --- | --- | --- | --- |
| 陌生任务跨来源整理费力 | 具体模块清单和可编辑条件 | 准备时间、平台切换、返工次数 | 熟悉任务靠记忆更快 |
| 用户不确定已有物品本次能否使用 | 已有/准备/未知分离，允许更正 | 重复购买/现场补救及实际成本 | 用户宁可到场补齐 |
| 天气、人群、活动让通用清单失效 | 出行输入继承、数量、本人/儿童、雨雪/下水条件 | 需要再追问的次数、关键遗漏及不适用项 | 用户本来已有成熟个人清单 |
| 直接导购降低信任 | 先核对、允许不买、来源/目录未知透明 | 用户对候选的采用理由与信任评分 | 固定平台和品牌已足够 |
| 反馈能指导内容迭代 | 清单评价、自报结果、人工治理 | 多人重复问题是否收敛并在复测改善 | 点“有帮助”未必与任务效果相关 |

价值尚未量化。后续记录“节省时间×任务频次”“避免的漏项及后果”“新增核对负担”，同时看净收益。

## 3. 场景选择与优先级

候选：首次长途/国际旅行、首次租房入住、首次养猫。短途熟悉旅行作负向对照。本轮旅行是最新缺陷复现与设计主案例，不能因此宣布旅行需求规模最大。

下一步先对样本去重并重建最近真实任务。以发生中的真实任务招募，优先看用户是否已主动查找、整理、修改或承受明确漏项代价。只有反复出现实际负担，才投入更深目录与自动化。

商业路径是后续假设：获准商品链接/导购或付费准备服务。当前缺真实SKU、归因、客单价、任务频次、佣金和成本，不能估算ROI。允许“全复用、不购买”的成功任务，避免商业指标推动过度采购。

## 4. 研究决策追溯

欧洲旅行经历 → 初版任务到采购流程。
短途低需求与到场补买反例 → 缩小人群、支持不需要与阶段补齐。
衣柜可用性和试衣差异 → 不从清单类型推断拥有/购买。
养猫来源顾虑 → 区分清单正确、商品可信和渠道信任。
最新人工验收反馈 → 将“需要购买”改为“需要准备”，新增天气/天数/同行对象等验收要求。
