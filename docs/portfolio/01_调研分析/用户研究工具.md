# 用户研究工具包

一句话：先还原最近一次真实任务，再测试产品；问卷、访谈和主持式任务测试分别回答不同问题。

状态：可执行草案，2026-10-25；本轮没有新招募、发卷、访谈或回收数据。

## 1. 样本台账与筛选

先建立匿名编号映射，去重n=5、A–D、CAT-01、TRIP-02。记录：来源/日期、是否完整原始材料、任务发生时间、首次程度、是否看过产品、重叠关系、引用许可。未确认重叠时不计算总样本数。

筛选问题：

1. 近3个月是否完成或未来1个月是否准备旅行/搬家入住/接猫？选最近一次具体任务。
2. 这是第一次、陌生任务还是熟悉的重复任务？涉及几位同行者/家庭成员？
3. 当时/现在如何确认要准备的物品？可否展示去标识化清单或过程？
4. 是否愿意参加约30分钟任务回放？不要求购买，不收集账号密码。

首轮建议选择一个主场景5位、相近复杂场景5位、熟悉短途负向对照3位；这是探索招募计划，无统计代表性。

## 2. 关键事件访谈提纲

- 最近一次任务何时开始准备？按时间还原第一步到完成；用了哪些来源和工具？
- 具体哪件物品最难判断？为什么？后来如何决定？
- 是否真的记录过清单？请展示或复述实际内容，不先介绍ShopMind。
- “家里有”是否意味着本次拿得到且可用？最近一次反例是什么？
- 有无遗漏、重复买、临时补买？每次实际造成时间/金钱/行程后果多少？也记录没有问题的情况。
- 天气、天数、同行小孩、游泳、下雨下雪、洗衣条件分别如何改变准备？
- 为何选择原渠道或当地购买？何时宁可不买/替代？
- 最后再展示概念：愿不愿实际用自己的任务试一次？观察实际操作，不用“你会不会用”当采用证据。

记录表字段：匿名编号｜真实事件｜行为/原话（分开）｜证据附件｜痛点后果｜现有替代｜解释假设｜反证｜下一步。缺逐字记录时只能标研究者转述。

## 3. 探索问卷（访谈后修订）

先用5位做题意认知测试，再考虑60–90份定向探索样本。不可将此计划写成已回收人数。

1. 最近一次真实任务类别、发生时间、陌生程度。
2. 准备提前量、同行人数/儿童年龄段（可跳过敏感项）。
3. 使用来源多选：记忆、熟人、笔记、社区、清单App、电商、其他。
4. 是否复制/改写清单？实际操作次数与耗时，允许“不知道”。
5. 是否逐项确认已有、需要、未知？拥有但拿不到发生过吗？
6. 最近一次遗漏/重复/补救：无/有/记不清；有则说明物品和后果。
7. 选择：提前备齐/先基础后补/到场解决/按具体品类决定，并说明原因。
8. 最困难环节排序：想清要带什么、数量/条件、确认已有、比较商品、完成购买、没有困难。
9. 假设产品概念展示后：担心什么？来源不可信、填写麻烦、推销、隐私、无必要、其他。
10. 愿否用下一次真实任务试用？单独自愿留联系渠道，与问卷答案隔离保存。

分析按场景/陌生程度分组，报告每题有效分母、缺失和招募方式。避免诱导“是否经常焦虑漏买”，避免把购买意向当实际转化。

## 4. 主持式任务测试

计划10–15位目标用户，每人两个难度相近任务，A为用户现有方式、B为ShopMind，AB/BA顺序平衡；同一个已完成任务不反复练习以免学习效应。无法匹配任务时如实记录难度差异。

主持人只在必要时提示，并分别记独立完成与提示后完成。目标完成：能说明清单条件、明确未知与可不买项，完成缺项决策；不要求出现购买。

记录：参与者/任务/工具版本｜开始与结束时间｜提示次数｜增删改条目｜关键遗漏/多余项｜非商品误操作｜状态误解｜候选是否有用｜是否完成｜放弃原因｜信心前后1–5｜来源可信度及开放反馈。

结束后问：哪一步最费力？哪条建议不适合？是否会继续用自己的任务？为何？
报告保留失败与负例。先判断可用性与价值方向，再决定是否做线上A/B。
