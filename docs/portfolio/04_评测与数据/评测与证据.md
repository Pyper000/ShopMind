## 2. 回归集和质量维度

固定[4类回归集](../../../eval/shopmind_mvp_regression_v1.json)：已知海边、语义成年猫、狗猫冲突、社区旧物义卖。测试位于[回归测试](../../../tests/test_shopmind_regression_eval.py)。开放场景结构断言与真实模型SSE分开看；固定测试不能替代随机真实生成评估。

下一版回归必须覆盖：

| 层 | 样例 | 核心断言 |
| --- | --- | --- |
| 路由 | 猫语义改写、狗/犬冲突、多意图 | 错对象阻断；低置信回退 |
| 结构 | 全新场景、空数组、重复项、泛化大类 | 2–6模块、具体项、顶层集合一致 |
| 状态 | 证件准备、已有、未知、否定/纠正 | 不误搜、不擅自推断拥有 |
| 旅行上下文 | 东京3日→本人+5岁孩子→海边游泳→不下水→改札幌/日期 | 对象/天数继承正确，新行程重取天气 |
| 天气条件 | 热/冷、雨/雪/高UV、缺日期、城市歧义、API故障 | 条件与类别对应，降级透明不阻断基础清单 |
| 商品 | 无目录、跨品类、预算变更 | 无匹配如实提示、硬约束不被语义分数覆盖 |
| 记忆/治理 | 未授权、撤回、匿名候选、未评测发布、回退 | 默认关闭、不可越权、不自动发布 |

高UV的真实复现说明，现有绿灯不能代表覆盖率充足。旧阶段1狗样例还出现过药品条目，应按高风险内容单独复核；即使后续prompt收紧，也不把早期结构验收当内容安全通过。

## 5. 目标与门槛

以下是拟定验收门槛，需内容审核和首轮基线后冻结，不冒充已达指标：

- 发布阻断：已知固定回归中的对象误路由、未确认搜索、非商品搜索、未授权记忆、API HTML误回退、高UV崩溃为0例。
- 清单结构：固定验收集100%符合契约；生成失败另计，不能剔除后报成功。
- 内容：关键物品的遗漏/条件错误由参考答案与双人裁决判定；专业高风险条目单独审核，不用文本相似度代替。
- 性能：采集每层至少30次初步分布再设SLO，样本不足不宣称稳定P95；成本金额需供应商实际计价。
- 用户价值：先得到任务时间、完成、遗漏和信心基线，再定义可检测改善幅度，避免拍脑袋承诺20%提升。

## 6. A/B与消融设计（尚未执行）

先做10–15人的可用性对照，顺序AB/BA平衡，任务难度匹配，保留失败/提示与学习效应。此阶段用于发现问题，不声称统计显著性。

达到真实流量条件后：

| 项目 | 预注册方案 |
| --- | --- |
| 假设 | 结构化准备状态及明确缺项检索提高有效决策完成，并减少无用采购 |
| 对照A | 明确版本的基础清单流程；实验B增加一项待测能力，例如条件/数量结构化，保持商品供给一致 |
| 分流 | 用户级稳定随机分流，游客按稳定匿名标识；按任务复杂度分层；避免同一用户跨组污染 |
| 主指标 | 预先定义的有效决策完成率；不以商品点击或会话结束替代 |
| 护栏 | 关键遗漏/高风险错误、冗余采购、放弃率、时延、每成功任务成本、记忆授权投诉 |
| 分析 | 意向处理，报告启动任务分母、未完成与缺失；测试流量排除，检查分流比例异常 |
| 样本量 | 先测基线p0、最小可检测差异、alpha=0.05与power=0.8，再按用户聚类/重复任务调整；目前不填虚构样本量 |
| 决策 | 预定时点分析；主指标改善且护栏不过线才扩大；恶化或无增量则保留简单版 |

技术消融另做：规则/模板 vs 加LLM语义理解；无天气 vs 有天气；仅全量召回 vs 按槽位增量复用。一次只改变一个因素，使用未参与调参的任务和人工盲评，不能把三个改进捆在一起归因。
