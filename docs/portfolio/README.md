## 证据使用规则

1. “实现存在”以代码/API/测试为据；“本地跑通”以具体日期的 SSE/截图/验收为据。
2. “用户有效”需要真实任务结果与对照；“购买成功”在本项目仅能表达用户自报。
3. 样本重叠未知，不合并访谈人数；反馈测试数据不进入用户价值结论。
4. 原型中的本人/儿童完整服装拆分是目标交互，尚未完整验收；不当作已上线能力。
5. 整理前的入口文档保存在[历史版本](历史版本/20261025整理前/README.md)，历史数据不改写成当前结果。

建议优先共享此文件夹，按提问打开原型、PRD、代码锚点或原始证据；无需依赖单一 PDF。
